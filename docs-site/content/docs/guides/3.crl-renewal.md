# CRL renewal for web servers

When uPKI CLI is installed on a TLS server that performs client certificate verification, the server needs a current CRL. The repository includes example systemd units for this: `upki-cli-crl.service` and `upki-cli-crl.timer`.

## How it works

`upki-cli-crl.service` runs `client.py crl` to download a fresh CRL into `~/.upki/crl.pem`, then immediately restarts Nginx (or Apache) so the new list is loaded.

## Setup

### 1. Copy the units

```bash
sudo cp upki-cli-crl.service /etc/systemd/system/upki-cli-crl.service
sudo cp upki-cli-crl.timer   /etc/systemd/system/upki-cli-crl.timer
```

### 2. Edit the service unit

Open `/etc/systemd/system/upki-cli-crl.service` and adjust the values for your environment:

```ini
[Unit]
Description=µPki client CRL download service
ConditionACPower=true
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=youruser
Group=yourgroup
Restart=on-failure
WorkingDirectory=/opt/upki-cli
ExecStart=/usr/bin/python3 ./client.py --url https://certificates.example.com crl
ExecStartPost=/usr/sbin/service nginx restart
# ExecStartPost=/usr/sbin/service apache2 restart

[Install]
WantedBy=upki-cli-crl.timer
```

- Set `User` and `Group` to the user that owns the uPKI CLI installation
- Set `WorkingDirectory` to the directory containing `client.py`
- Set `ExecStartPost` to the restart command for your web server (`nginx` or `apache2`)

### 3. Configure Nginx to use the CRL

In your Nginx site configuration:

```nginx
ssl_client_certificate /path/to/ca.crt;
ssl_crl                /home/youruser/.upki/crl.pem;
ssl_verify_client      on;
```

Replace `~` with the absolute home directory of the service user, because Nginx does not expand `~` in configuration files.

### 4. Enable the timer

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now upki-cli-crl.timer
```

### 5. Verify

```bash
systemctl list-timers upki-cli-crl.timer
journalctl -u upki-cli-crl.service -n 20
```

## Timer schedule

The timer fires once per day at 02:00 AM with a randomised delay of up to one hour — matching the certificate renewal timer to ensure the CRL is always refreshed after renewals complete.

```ini
[Timer]
OnBootSec=1min
OnCalendar=*-*-* 02:00:00
RandomizedDelaySec=1hour
Unit=upki-cli-crl.service
Persistent=true
```
