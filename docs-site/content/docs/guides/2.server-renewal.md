# Automatic server renewal

The `install.sh` script creates two systemd units that run `client.py renew` automatically every day. This section explains how to verify, customise, and troubleshoot them.

## How the timer works

| Unit | Purpose |
|---|---|
| `upki-cli.service` | Runs `client.py --url <RA_URL> renew` as your user |
| `upki-cli.timer` | Triggers `upki-cli.service` every day at 02:00 AM, with a randomised delay of up to one hour |

The one-hour random delay (`RandomizedDelaySec=1hour`) prevents all clients from hitting the RA simultaneously when many hosts are running uPKI CLI.

## Verify the timer

```bash
systemctl list-timers upki-cli.timer
```

Expected output includes a `NEXT` timestamp around 02:00 of the following day.

```bash
systemctl status upki-cli.timer
systemctl status upki-cli.service
```

## View renewal logs

```bash
journalctl -u upki-cli.service -n 50
```

The log file at `~/.upki/.cli.log` also records each renewal attempt with timestamps.

## Enable on a new host after manual installation

If you installed dependencies manually (without `install.sh`), create the units by hand:

```bash
sudo tee /etc/systemd/system/upki-cli.service > /dev/null <<EOF
[Unit]
Description=µPki Client Renewal service
ConditionACPower=true
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=${USER}
Group=$(id -gn)
Restart=on-failure
ExecStart=$(pwd)/client.py --url https://certificates.example.com renew

[Install]
WantedBy=upki-cli.timer
EOF

sudo tee /etc/systemd/system/upki-cli.timer > /dev/null <<EOF
[Unit]
Description=µPki Client certificate renewal service timer

[Timer]
OnBootSec=1min
OnCalendar=*-*-* 02:00:00
RandomizedDelaySec=1hour
Unit=upki-cli.service
Persistent=true

[Install]
WantedBy=timers.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now upki-cli.timer
```

Replace `https://certificates.example.com` with your actual RA URL and adjust the `ExecStart` path to the absolute location of `client.py`.

## Disable the timer

```bash
sudo systemctl disable --now upki-cli.timer
```
