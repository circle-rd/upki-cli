# Global flags

These flags must appear before the subcommand name and apply to every command.

## Reference

| Flag | Short | Default | Description |
|---|---|---|---|
| `--url` | `-u` | *(required)* | HTTPS base URL of the µPKI-RA instance. A bare hostname is treated as `https://`. Using `http://` triggers a confirmation prompt. |
| `--path` | `-p` | `~/.upki` | Directory where private keys, CSRs, and certificates are stored. Created automatically if it does not exist. |
| `--quiet` | `-q` | `false` | Suppress informational output. Only errors are printed. Sets the log level to `ERROR`. |
| `--debug` | `-d` | `false` | Enable verbose debug output. Sets the log level to `DEBUG`. |
| `--json` | `-j` | `false` | Format output as JSON. |

## Examples

### Use a custom data directory

```bash
./client.py --url https://certificates.example.com \
            --path /srv/pki \
            renew
```

### Enable debug output

```bash
./client.py --url https://certificates.example.com \
            --debug \
            add --name myserver.example.com --profile server
```

### Suppress all non-error output

```bash
./client.py --url https://certificates.example.com \
            --quiet \
            renew
```

## Built-in help

Every command prints a help message when called with `--help`:

```bash
# Global help
./client.py --help

# Command-specific help
./client.py --url https://certificates.example.com add --help
```
