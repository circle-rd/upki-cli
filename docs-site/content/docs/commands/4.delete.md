# delete

Remove a certificate node from the local registry and delete every associated file from disk. This operation is local only — it does not revoke the certificate on the RA or CA.

## Synopsis

```bash
./client.py --url <RA_URL> delete [options]
```

## Options

| Flag | Short | Default | Description |
|---|---|---|---|
| `--name` | `-n` | *(interactive)* | Common Name of the node to delete. If omitted, you are prompted. |
| `--profile` | `-p` | *(interactive)* | Certificate profile of the node to delete. If omitted, you are prompted. |

## Example

```bash
./client.py --url https://certificates.example.com delete \
    --name myserver.example.com \
    --profile server
```

## Files deleted

The following files are removed from the data directory:

| File | Condition |
|---|---|
| `{profile}.{name}.key` | Always |
| `{profile}.{name}.csr` | If present |
| `{profile}.{name}.crt` | Always |
| `{profile}.{name}.pem` | Always |
| `{profile}.{name}.p12` | Only if the node was enrolled with `--p12` |

Each file is `chmod 600` before deletion to ensure it can be removed even if it was written read-only.

::callout{type="warning"}
`delete` does not revoke the certificate on the CA. If you need to revoke it, do so via the µPKI-RA administration interface before deleting locally.
::
