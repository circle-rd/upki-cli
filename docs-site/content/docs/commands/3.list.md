# list

Display all certificate nodes registered in the local registry (`~/.upki/cli.nodes.json`). This reflects what uPKI CLI knows about locally, not the state on the RA server.

## Synopsis

```bash
./client.py --url <RA_URL> list
```

## Options

The `list` command takes no command-specific options. All global flags apply.

## Example

```bash
./client.py --url https://certificates.example.com list
```

Output:

```
..:: Nodes found in config ::..
  - [0] myserver.example.com    (server)
  - [1] mydevice.example.com    (user)
```

Each line shows the index, Common Name, and certificate profile of the registered node.

## Notes

- `list` reads from the local JSON file only and does not contact the RA
- If no nodes have been enrolled, the command outputs `No node found in config.` and returns `False`
