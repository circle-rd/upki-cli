# renew

Renew every certificate that has been enrolled on this host. The command iterates the local registry (`~/.upki/cli.nodes.json`), re-enrolls each certificate via ACME, and overwrites the existing key and certificate files.

## Synopsis

```bash
./client.py --url <RA_URL> renew
```

## Options

The `renew` command takes no command-specific options. All global flags apply.

## How renewal works

For each node in the registry:

1. A new EC P-256 private key is generated and replaces the old one
2. A new CSR is submitted to the RA via ACME
3. The signed certificate and PEM bundle overwrite existing files
4. If the original enrollment used `--p12`, a new P12 bundle is written
5. If `--firefox` or `--chrome` was set on the original enrollment, the renewed certificate is imported into the browser trust store

Renewal failures for individual nodes are logged as warnings and do not stop the loop — the remaining nodes continue to be renewed.

## Example

```bash
./client.py --url https://certificates.example.com renew
```

## Automating renewal

The `install.sh` script creates a systemd service and timer that run this command automatically. See the [automatic renewal guide](/docs/guides/server-renewal) for details.

::callout{type="info"}
Each renewal generates a completely new private key. The old key is overwritten, not archived. If you need the old key for auditing, back up `~/.upki/` before running `renew`.
::
