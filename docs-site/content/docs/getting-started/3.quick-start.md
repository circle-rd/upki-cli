# Quick start

This guide assumes you have completed [installation](/docs/getting-started/installation) and have the HTTPS URL of a running µPKI-RA instance.

## Step 1 — Add a certificate

Run the `add` command. uPKI CLI will:

1. Download and pin the CA certificate from the RA
2. Create a new EC P-256 account key and register an ACME account
3. Prompt you for a Common Name and profile (if not supplied as flags)
4. Generate a node EC P-256 private key and Certificate Signing Request
5. Submit an ACME order and retrieve the signed certificate

```bash
./client.py --url https://certificates.example.com add
```

When prompted:

```
Enter your node name (CN): myserver.example.com
Enter your profile: server
```

The certificate files appear in `~/.upki/`:

```
~/.upki/server.myserver.example.com.key   # EC P-256 private key (mode 0400)
~/.upki/server.myserver.example.com.crt   # PEM certificate    (mode 0444)
~/.upki/server.myserver.example.com.pem   # cert + key bundle  (mode 0400)
```

## Step 2 — Verify the certificate

```bash
openssl x509 -in ~/.upki/server.myserver.example.com.crt -noout -subject -issuer -dates
```

## Step 3 — List registered certificates

```bash
./client.py --url https://certificates.example.com list
```

Output:

```
..:: Nodes found in config ::..
  - [0] myserver.example.com    (server)
```

## Step 4 — Renew manually

```bash
./client.py --url https://certificates.example.com renew
```

This renews every certificate in the local registry. The systemd timer created by `install.sh` runs this command automatically every day at 02:00 AM.
