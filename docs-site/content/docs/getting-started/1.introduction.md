# Introduction

uPKI CLI (`upki-cli`) is the client application for the µPKI private PKI stack. It runs on any host that needs an X.509 certificate — a server, a workstation, or a developer machine — and speaks to a [µPKI-RA](https://github.com/circle-rd/upki-ra) Registration Authority over HTTPS using the ACME v2 protocol (RFC 8555).

## The µPKI stack

µPKI is designed to provide a complete private certificate authority without cloud dependencies. It consists of three components:

| Component | Role |
|---|---|
| [µPKI-CA](https://github.com/circle-rd/upki) | Certification Authority — issues, renews, and revokes X.509 certificates |
| [µPKI-RA](https://github.com/circle-rd/upki-ra) | Registration Authority — ACME v2 front-end to the CA |
| **µPKI-CLI** (this project) | Client — requests and manages certificates on an end host |

uPKI CLI sits at the outermost layer: it generates EC P-256 private keys locally, sends Certificate Signing Requests to the RA via ACME, writes the issued certificates to disk, and optionally imports them into browser trust stores.

## What uPKI CLI does

- Enrolls new certificates for a given Common Name and certificate profile
- Stores private keys, PEM bundles, and optional PKCS#12 files under `~/.upki/`
- Maintains a local registry (`cli.nodes.json`) so every enrolled certificate can be renewed in a single command
- Runs as a daily systemd timer to automate certificate renewal before expiry
- Downloads and stores the CA certificate and CRL from the RA
- Imports the CA and user certificates into Firefox or Chrome NSS databases

## What uPKI CLI does not do

- It does not generate Certificate Revocation List entries — that is handled by µPKI-CA
- It does not expose any HTTP or WebSocket API — it is a command-line tool only
- It does not support ACME challenge types (HTTP-01, DNS-01) — it relies on the RA's pre-authorisation model

## Requirements

| Requirement | Version |
|---|---|
| Python | ≥ 3.11 |
| A running µPKI-RA instance | Any version supporting ACME v2 |
| `libnss3-tools` | Required only for Firefox / Chrome integration |

::callout{type="warning"}
uPKI CLI has been tested on Python 3.11, 3.12, and 3.13 on Linux. macOS is supported for browser integration (Keychain). Windows is not supported for browser integration.
::
