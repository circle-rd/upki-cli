# Installation

## Prerequisites

uPKI CLI requires the following system packages. Install them before proceeding:

```bash
sudo apt update
sudo apt -y install build-essential libssl-dev libffi-dev python3-dev python3-pip git libnss3-tools
```

`libnss3-tools` provides the `certutil` and `pk12util` utilities that uPKI CLI uses to import certificates into Firefox and Chrome NSS databases. It is only strictly required if you plan to use the `--firefox` or `--chrome` flags.

## Clone the repository

```bash
git clone https://github.com/circle-rd/upki-cli
cd upki-cli
```

## Install with the bundled script

The `install.sh` script installs Python dependencies, creates a systemd service and timer for automatic certificate renewal, and optionally enables them on boot.

```bash
./install.sh --url https://certificates.example.com
```

Replace `https://certificates.example.com` with the actual HTTPS base URL of your µPKI-RA instance.

The script will:

1. Run `apt update && apt upgrade`
2. Install system packages listed above
3. Run `pip3 install -r requirements.txt`
4. Create `/etc/systemd/system/upki-cli.service` and `upki-cli.timer`
5. Ask whether to enable the timer on boot

::callout{type="info"}
The install script must be run as root (or with sudo). It sets the systemd service to run as the current user so certificate files are owned by you, not root.
::

## Manual Python dependency installation

If you prefer not to run the install script, install the Python packages directly:

```bash
pip3 install -r requirements.txt
```

The dependencies are:

| Package | Minimum version |
|---|---|
| `cryptography` | ≥ 42.0.0 |
| `httpx` | ≥ 0.27.0 |
| `dnspython` | ≥ 2.6.0 |
| `setuptools` | ≥ 68.0.0 |

## File layout after installation

| Path | Description |
|---|---|
| `~/.upki/` | Default data directory — created automatically on first run |
| `~/.upki/ca.crt` | CA certificate downloaded from the RA |
| `~/.upki/crl.pem` | Certificate Revocation List |
| `~/.upki/acme_account.key` | ACME account EC P-256 private key |
| `~/.upki/acme_account.json` | ACME account ID |
| `~/.upki/cli.nodes.json` | Local node registry |
| `~/.upki/.cli.log` | Rotating log file |

You can override the data directory with the global `--path` flag on every invocation.
