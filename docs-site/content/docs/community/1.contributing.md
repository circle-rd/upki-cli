# Contributing

Contributions to uPKI CLI are welcome. Please read the project [CONTRIBUTING.md](https://github.com/circle-rd/upki-cli/blob/main/CONTRIBUTING.md) before submitting a pull request.

## Project structure

```
upki-cli/
├── __metadata.py          # Version and author metadata
├── requirements.txt       # Python dependencies
├── setup.py               # Package configuration
├── install.sh             # System installation helper
├── client.py              # CLI entry point and argument parser
├── upki-cli.sh            # Convenience shell wrapper
├── upki-cli-crl.service   # Example systemd service for CRL refresh
├── upki-cli-crl.timer     # Example systemd timer for CRL refresh
└── client/
    ├── __init__.py        # Public exports: UPKILogger, Collection, Bot
    ├── acme_client.py     # ACME v2 (RFC 8555) client — key gen, JWS, enrollment
    ├── bot.py             # High-level command orchestrator
    ├── collection.py      # Local node registry (cli.nodes.json)
    └── upkiLogger.py      # Rotating file logger with coloured console output
```

## Development setup

```bash
git clone https://github.com/circle-rd/upki-cli
cd upki-cli
pip3 install -r requirements.txt
```

## Running locally

```bash
./client.py --url https://certificates.example.com --help
```

## Code style

- Python 3.11+ — type annotations are used throughout
- No external linting configuration is currently committed; follow the existing patterns
- Keep `acme_client.py` free of subprocess calls — all cryptographic operations use the `cryptography` library directly
